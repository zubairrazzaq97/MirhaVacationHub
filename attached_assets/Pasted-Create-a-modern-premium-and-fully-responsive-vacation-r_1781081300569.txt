Create a modern, premium, and fully responsive vacation rental website called Mirha Vacation Homes, a Dubai-based company specializing in luxury holiday apartments, furnished rooms, and short-term vacation rentals in Dubai, United Arab Emirates. The website should have a professional and elegant design inspired by leading platforms such as Airbnb and Booking.com while maintaining a unique brand identity. The primary goal of the website is to allow customers to easily browse available apartments and rooms, view detailed property information, check amenities and appliances, communicate with the company, and make online booking requests for weekend stays, holidays, business trips, or short-term living.

The homepage should include a visually appealing hero section featuring Dubai's skyline, a property search and booking form, featured apartments, customer testimonials, and a section explaining why customers should choose Mirha Vacation Homes. The website should provide dedicated pages for Home, About Us, Properties, Property Details, Booking, Contact, and Customer Support. The About Us page should introduce the company, its mission and vision, and include a professional profile of the CEO, Ubaid Sufyan. The Properties page should display all available apartments, holiday homes, and rooms with advanced filters such as location, price, number of guests, and property type.

Each property detail page should contain a high-quality image gallery, property description, pricing information, location map, availability calendar, and a complete list of amenities and appliances available in the apartment or room, including WiFi, air conditioning, smart TV, refrigerator, microwave, washing machine, kitchen facilities, coffee machine, parking, swimming pool, gym access, and security services. Customers should be able to submit booking requests by selecting check-in and check-out dates, number of guests, and personal details. The system should automatically store booking information in a secure database and send confirmation notifications.

The website must also include a customer inquiry and messaging system where visitors can contact the company, request property details, ask questions, and submit inquiries. All messages should be stored in a database and accessible through an admin dashboard. The Contact page should include a contact form, phone number, WhatsApp button, email address, office location in Dubai, and Google Maps integration. An automatic email response system should acknowledge customer inquiries immediately.

A secure admin dashboard should be developed to allow administrators to add, edit, and delete properties, upload apartment images, manage bookings, view customer details, respond to inquiries, update property availability, and monitor website activity. The backend should include a database structure for properties, bookings, and customer messages. Use modern technologies such as Next.js, React.js, Tailwind CSS, Node.js, Express.js, and MongoDB. The website should be optimized for SEO, mobile devices, performance, security, and accessibility. Include social media integration, newsletter subscription functionality, and a professional footer containing company information, quick links, contact details, and copyright information.

The final result should be a luxury, high-performance, production-ready vacation rental platform for Mirha Vacation Homes that provides a seamless user experience for browsing, booking, and communicating with the company while giving administrators complete control over property management, bookings, customer inquiries, and data storage.
